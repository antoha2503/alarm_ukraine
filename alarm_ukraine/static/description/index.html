Ukraine Alarm

Оперативні сповіщення про повітряну тривогу у вашому Odoo — щоб команда бачила важливий статус регіону прямо в робочому середовищі.

Дані оновлюються кожні 15 секунд.
Це ключова особливість модуля: актуальний стан перевіряється з інтервалом 15 секунд.

Що робить модуль

Ukraine Alarm додає до Odoo зручний індикатор стану повітряної тривоги для обраного регіону. Під час тривоги користувач побачить помітне сповіщення; модуль також може відтворювати звук та показувати анімацію, якщо ці можливості увімкнені у вашій конфігурації.

Зрозумілий індикатор
Стан тривоги доступний без переходу до окремої сторінки.
Швидке оновлення
Перевірка даних відбувається раз на 15 секунд.
Ваш API-ключ
Підтримується персональний ключ API для стабільнішої роботи.

Як це виглядає в Odoo

Індикатор у верхній панелі: швидке відображення стану обраного регіону.

Джерело звідки берется регіон співробітника

Джерело даних і персональний API

Модуль отримує інформацію з сервісу map.ukrainealarm.com. Для надійної роботи рекомендуємо використовувати власний API-ключ, отриманий у цього постачальника даних.

Отримати персональний API-ключ можно по посиланню https://api.ukrainealarm.com

Безпека: не публікуйте свій API-ключ у відкритому доступі, не додавайте його до скриншотів, репозиторіїв чи публічних повідомлень.

Налаштування за кілька кроків

  1. Встановіть модуль Ukraine Alarm у вашій базі Odoo.
  2. Відкрийте загальні налаштування Odoo та знайдіть параметри Ukraine Alarm.
  3. За можливості, введіть персональний API-ключ.
  4. Збережіть налаштування. Модуль почне оновлювати статус кожні 15 секунд.
Сумісність: Регіон кожного співробітника буде братися з його карти модуля Співробітники. Вкладка "Особиста інформація" - поле "Домашня адреса"

Важливі пояснення

Напис «КЕШ» перед назвою регіону — це не помилка.

Він може тимчасово з’являтися, коли модуль відображає кешовані дані. Це нормальна поведінка, яка допомагає зберігати стабільність роботи та зменшувати зайві звернення до API.

Регіони та їхні коди важливі.

Перелік регіонів України додається разом із модулем. Їхні внутрішні коди використовуються для коректного запиту до API, тому не змінюйте та не видаляйте ці коди без розуміння наслідків. Неправильний код може призвести до відсутності або некоректності даних.
