# alarm_ukraine
Alerm in Ukraine — модуль для Odoo, який відображає актуальний
        статус повітряної тривоги для регіону користувача безпосередньо
        у верхній панелі Odoo.
        Основні можливості:
        - Відображення статусу повітряної тривоги у верхній панелі Odoo.
        - Автоматичне визначення регіону користувача.
        - Оновлення інформації кожні 15 секунд.
        - Відображення назви регіону та часу останнього оновлення.
        - Візуальне повідомлення про початок повітряної тривоги.
        - Звукове сповіщення при початку тривоги.
        - Відображення додаткової анімації під час тривоги.
        - Можливість використання власного API користувача.
        - Дані отримуються з офіційного сервісу «Повітряна тривога».
        Джерело даних:
        https://map.ukrainealarm.com
        Для роботи модуля необхідний API Key Ukraine Alarm.
        API Key можна отримати через офіційний сервіс Ukraine Alarm.
        Важливо:
        інформація оновлюється кожні 15 секунд. Напис «КЕШ», який іноді
        може відображатися перед назвою регіону, не є помилкою модуля.
        Регіони та відповідні коди завантажуються під час встановлення
        модуля. Коди регіонів є важливою частиною роботи модуля та
        використовуються для отримання актуальної інформації з API.
